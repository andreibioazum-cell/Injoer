# Injoer (debug, offline)

Офлайн 3D-песочница в духе Роблокса. Старой игры больше нет:
приложение сразу грузится в 3D-мир, без меню и онлайна.

- **Настоящее 3D** — перспективная проекция, объёмные кубы с освещением
  граней, туман до горизонта, свободная орбита-камера (тяни пальцем).
- **Персонаж** — блочный человечек из кубов: ноги и руки качаются
  при ходьбе, прыжок с тенью.
- **Джойстик** — слева, с тем же чувством, что в Кубик Батл
  (полная скорость за маленькой мёртвой зоной); зелёная кнопка — прыжок.
- **Офлайн и дебаг** — сети нет совсем, APK под debug-подпись
  (`android:debuggable="true"`).

Управление: стик — идти (относительно камеры), тап по зелёной кнопке —
прыжок, тяни по экрану — повернуть камеру.
