# Injoer (debug, offline)

Debug-подпись, без онлайна: игра переделана в офлайн-песочницу в духе Роблокса.

- **Мир 3D** — пункт «Мир 3D» в меню режимов: baseplate с шипами, блоки,
  блочный персонаж от третьего лица, прыжок.
- **Джойстик как в Кубик Батл** — тот же виртуальный стик слева
  (та же мёртвая зона и скорость), кнопка прыжка справа.
- **Офлайн** — онлайн-бой, топ и вход в аккаунт отключены, автологин выключен.
- APK собирается и подписывается **debug-ключом** (`android:debuggable="true"`).

Старый бой 2D (соло против бота) оставлен как бонусный режим «Соло».
